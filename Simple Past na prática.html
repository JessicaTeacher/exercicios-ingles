Revisão rápida das regras
  • Verbos regulares: acrescente -ed (watch → watched; study → studied).
  • Verbos irregulares mudam de forma (go → went; buy → bought; see → saw).
  • Negativa: did not + verbo base (She did not go).
  • Pergunta: Did + sujeito + verbo base (Did you see Tom?).
